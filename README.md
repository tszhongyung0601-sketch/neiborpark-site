# 鄰停車位共享 · 形象頁

社區車位共享平台 [鄰停](https://neiborpark.pages.dev/) 的對外形象頁，受眾是**社區管委會與住戶**。

單檔靜態頁：`index.html` + `logo2.png`，沒有建置步驟、沒有相依套件。
直接開檔就能看，丟到任何靜態主機（Cloudflare Pages / GitHub Pages）也是原樣。

## 這一頁在講什麼

一句話：**鄰停是社區內部的車位媒合與對帳工具，不是金流平台。**
平台只跟管委會收訂閱費，住戶之間的現金往來不經手、不抽成、不代收。

版面順序刻意照著管委會的疑慮排：

1. Hero — 白天空著的車位 vs 晚上繞第三圈，右側是住戶端「即時車位看板」示意
2. 一句話定義帶
3. 現況三痛點 — 時段沒人知道、借還沒紀錄、管委會變人工排程
4. 四步驟 — 開放時段 → 看板看到 → 申請＋LINE 通知 → 現金投信箱雙方確認
5. **錢怎麼算** — App 算金額 / 住戶投信箱 / 雙向對帳，最容易被誤會的一段獨立講
6. 車主 / 借用鄰居 / 管委會 三種身分各拿到什麼
7. 常見問題六題
8. CTA — 加 LINE 官方帳號

主 CTA 一律指向 LINE 官方帳號 `@694embuk`。**全頁不出現任何價格**，費用一律導向洽詢。
